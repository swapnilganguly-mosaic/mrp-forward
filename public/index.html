Score Formula  ▶
Score = Urgency x Strategic Weight x Material Feasibility
Urgency = 1 / FG DOC  |  FG DOC (days) = FG Stock (units) / DRR (units/day)
Material Feasibility = min(RM DOC, PM DOC) / Target RM DOC  [capped at 1]
RM DOC = min over all RM materials of [ RM Stock (kg) / (RM% x Pack Size kg x DRR) ]  — bottleneck material
PM DOC = min over all PM materials of [ PM Stock (units) / (PM Qty/unit x DRR) ]  — bottleneck material
DRR = Jun Units/day (embedded)  |  RM/PM Stock = live sync from MRP Tool  |  FG Stock = SIH + SIT (manual upload)  |  Target Run QTY = DRR x 13

Bulk paste demand

Paste three columns: sku_code, Month-1 units, Month-2 units (tab, comma, or space separated — one SKU per line). Two columns (sku, M1) also work and leave M2 unchanged. Matching is case-insensitive on the SKU code; existing demand for matched SKUs is overwritten.

Import demand from a file

Upload one spreadsheet listing each SKU and its Month-1 and Month-2 supply. The recipe (RM % & PM quantities per unit) is already built in — only the demand columns are read from this file. Accepted: .xlsx or .csv (not the older .xls). SKU codes are matched case-insensitively.
